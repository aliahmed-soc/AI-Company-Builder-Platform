# Release Gates

Status: Proposed for owner review. Gates are sequential; **no gate may be passed because the UI appears complete** — every criterion is test- or evidence-backed. PRD §22 launch gates (1–15) map onto the Closed beta gate.

| Gate | Required milestone | Functional criteria | Security criteria | Reliability criteria | Data criteria | Usage/cost criteria | Operational criteria | Documentation criteria | Owner approval | Blocking defects | Evidence required |
|---|---|---|---|---|---|---|---|---|---|---|---|
| **Development foundation** | M0 | Install, checks, tests, config validation run | Secret scan zero findings; boundary lint enforcing | CI stable | Migration discipline defined | n/a | Local dev works per docs | Scaffold + standards docs current | Not required | Any red CI | CI run links; boundary-violation negative proof |
| **Internal prototype** | M1–M2 | Slices A+B demo end to end | Isolation suite 100%; authz negative suite green; forged-claim tests green | Session resume; webhook replay safe | Tenant ownership immutable in schema | Usage events recorded per model call | Correlation IDs resolve traces | Module READMEs for shipped modules | Informal | P0/P1 security defects | Demo recordings/scripts + suite results |
| **Alpha (internal users)** | M3–M4 | Slices A–D demo; full planning loop | All prior + decision-record immutability | State-machine conformance suite green | Versioned objects supersede, never overwrite | Per-company usage queryable | Basic dashboards live | Updated architecture docs on any contract change | Yes — scope | Any trust-critical failure | Gate suite results + owner sign-off record |
| **Closed beta** | M5–M7 (all) | **Complete MVP loop E2E**; Slices A–F green; export works; revision works | **PRD launch gates 1–15 all test-backed and green**, incl. isolation 100%, approval negative set, stop ≤5s, secret zero-findings | Kill-and-resume, replay-zero-duplicates, failure-injection pass; restore drill within RTO/RPO (NFR-017) | Retention documented (P0-010); deletion/deactivation paths work; subprocessor register current (ADR-005) | Ledger↔rollup↔provider reconciliation clean (gate 7); caps enforce (NFR-015); eval-gate 10 areas ≥ thresholds (ADR-019) | Dashboards + alert tiers live; runbooks proven (at least restore + stop drills executed); on-call defined | Data-path disclosure copy live (ADR-003); user docs for the MVP loop; DoR/DoD in force | **Yes — explicit** | Zero open P0/P1; no known trust-critical defect | Recorded evidence per launch gate; drill logs; eval report; reconciliation report |
| **General MVP release** | Post-beta | Beta feedback triaged; usefulness ≥ targets (PRD §21) | Pen review completed, high+ closed (NFR-010) | NFR-003 availability measured over beta period | NFR-011 privacy items complete | D-02 commercial model decided and implemented (Phase 7+ billing) | Support model live (OQ-21) | Terms/ownership language final (D-07) | **Yes — explicit** | Zero P0/P1 | Beta metrics report + gate re-run |

**Audience restriction (binding):** the closed beta **excludes customers requiring strict data residency** (ADR-005). Beta onboarding materials must state the residency posture honestly; no unsupported residency claims anywhere.

Gate execution is a ticket (ACBP-P7-010): run the accumulated suites fresh, collect evidence, record owner decision. Diagram: `diagrams/04-release-gates.mmd`.
