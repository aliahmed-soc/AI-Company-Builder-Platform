# OWNER-APPROVALS.md — accepted owner decisions (gate answers)

_This file is the owner's approval inbox for the auto-pm loop. Entries under
"## Approved" are **accepted owner decisions** in the sense of CLAUDE.md's
canonical source priority #1, and may authorize actions that are otherwise
OWNER GATES. The agent marks an entry CONSUMED when it acts on it; consumed
entries are history and authorize nothing further. Anything not written here
remains a hard stop. Never put secrets or credentials in this file._

Approval lines must be explicit and scoped, e.g.:

- `APPROVED 2026-07-28: mark ACBP-P5-005 Done, mark PR #61 ready for review.`
- `APPROVED 2026-07-28: after P5-005 is merged, start the next backlog ticket (P5-006) on a new branch.`
- `APPROVED 2026-07-28: merge PR #61 to main under delegated merge authority, then delete the branch.`

Blanket approvals ("do whatever is next forever") are not valid — the agent
must ignore them.
