# Failure and Recovery

Status: Proposed. Governs NFR-005/006/007/019/020, TASK-006/007/009/010. Diagram: `diagrams/14`. Global rules: **no unlimited retries** — every retry policy is bounded with backoff (NFR-007); **non-idempotent actions are never retried without a safe idempotency mechanism** (invariant 8); user-facing status is always truthful (`unconfirmed` ≠ `failed` ≠ `completed`; invariant 20).
