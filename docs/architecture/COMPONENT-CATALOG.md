# Component Catalog

Status: Proposed (companion to `TECHNICAL-ARCHITECTURE-v1.md` §7). Deployment forms: **[M]** module inside the main backend (`api` and/or `worker` process), **[W]** dedicated worker process, **[I]** shared infrastructure, **[X]** external provider, **[F]** future standalone service candidate. No component is assumed to be a separately deployed service unless marked.
